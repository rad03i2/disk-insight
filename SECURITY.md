# Security Policy

Disk Insight is deliberately read-only and local. Please report suspected security issues privately through GitHub's security reporting facilities when available rather than publishing exploit details in a public issue.

## Scope
Security-sensitive areas include unsafe path traversal, unintended filesystem modification, symlink behavior, leakage of scanned path information, and dependency/supply-chain concerns.

The project never needs credentials, tokens, or API keys. Do not submit real secrets in issues, logs, tests, or examples.
