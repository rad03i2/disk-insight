# Contributing / المساهمة

Thanks for improving Disk Insight. Keep changes focused, safe, cross-platform, and read-only by default.

1. Use Python 3.10+.
2. Install development tools: `pip install -e . pytest ruff`.
3. Add or update tests for behavioral changes.
4. Run `ruff check src tests` and `pytest -q`.
5. Keep README examples synchronized with the real CLI.
6. Never commit credentials, personal scan reports, or generated filesystem data.

## العربية
شكرًا للمساهمة. حافظ على التغييرات مركزة وآمنة ومتوافقة مع الأنظمة المختلفة، وعلى مبدأ القراءة فقط افتراضيًا. أضف اختبارات لأي تغيير سلوكي، وشغّل `ruff` و`pytest`، ولا ترفع أسرارًا أو تقارير فحص شخصية إلى المستودع.
